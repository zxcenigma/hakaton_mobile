# Киса Копилка

Flutter-приложение с загрузкой, проверкой API и знакомством при первом запуске.

Запуск:

```sh
flutter pub get
flutter run
```

На старте приложение показывает логотип, декодирует изображения, подготавливает главный экран и проверяет API. Полоска отражает завершение этих этапов. Учитывается системное уменьшение анимации. При ошибке доступна повторная попытка.

После подготовки открывается форма имени и возраста. Возраст выбирается ползунком от 1 до 100, по умолчанию 18. Пустое имя не отправляется. При подтверждении выполняется:

```http
POST http://91.210.106.86:6767/auth/signup
Content-Type: application/json; charset=utf-8

{"username":"Саша","age":18}
```

Ответы 200 и 201 считаются успешными. Только после успешного ответа и сохранения профиля на устройстве открывается главный экран. При последующих запусках форма пропускается, но проверка сервера остаётся. При открытии дневника приложение входит по сохранённому username через `/auth/signin` и получает UUID из `/api/v1/users/me`. Токен используется для получения профиля и не сохраняется на устройстве.

Проверка доступности: `GET /`, ожидается 200. Если корень возвращает 404, используется `GET /openapi.json` с проверкой наличия `/auth/signup` в схеме. Таймаут одного запроса — 15 секунд. POST автоматически не повторяется. Для регистрации сервер должен принимать только `username` и `age`; приложение не генерирует email или пароль.

Адрес можно переопределить:

```sh
flutter run --dart-define=API_BASE_URL=https://your-api.example
```

HTTP-исключения Android и Apple ограничены `91.210.106.86`. Для другого HTTP-хоста нужно обновить настройки платформ. Исключения ATS по IP поддерживаются начиная с iOS 17 / macOS 14 ([Apple NSExceptionDomains](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsexceptiondomains)); старые версии Apple нужно проверять отдельно. В браузере HTTP API требует HTTP-страницы и разрешённого CORS на сервере.

Изображения находятся в `assets/image/`. Для пересоздания иконок и нативной заставки из `logo.png`:

```sh
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

Второе изображение `loading_page.png` используется как иллюстрация. Статичные текст и полоска с картинки обрезаются при отображении; под иллюстрацией находятся настоящие текст и полоска прогресса.

Проверки:

```sh
flutter analyze
flutter test
flutter build apk --debug
```

Дневник доступен по кнопке «Дневник» на главном экране: семь дней с понедельника, переключение недель, возврат к текущей неделе и обновление жестом вниз. События сохраняются через `/api/v1/diary/operations`, затем неделя загружается повторно. Типы: расход, доход, накопление (без привязки к цели). Расходы поддерживают 25 категорий API. Сумма — целое число рублей, как требует текущая схема сервера.
