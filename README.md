# Мобильное приложение "Киса Копилка"

![alt text](mobile_app/assets/image/logo.png)

### Идея: Приложение для учета дневника расходов/доходов/инвестиций. Анализ недельных/месячных/годовых данных. Подключение модели для выдачи определенных стрктурированных метрик. Внутриигровой баланс за ежедневный вход

### Стек технологий:
 - **Frontend** - Flutter
 - **Backend** - Python/FastAPI/Pydantic/SQLAlchemy/PostgreSQL/Alembic/Docker (1 сервис - монолит, разделенный хорошей структурой модулей)


### Запуск локального Backend

Из корня выполнить:
```bash
bash backend_init.sh up
```

* Скрипт предусматривает: 
  - миграцию данных; 
  - создание базового .env необходимого для работы;
  - генерацию публичного/закрытого ключа для ассиметричного шифрования JWT ключей;
  - а также другие функции запуска описанные ниже.


Произойдет поднятие 3 сервисов - PostgreSQL, Redis и Python в контейнерах.
```text
API будет доступно по адресу - **127.0.0.1:6767**
Документация будет доступна по адресу **127.0.0.1:6767/docs**
OpenAPI будет доступо по адресу **127.0.0.1:6767/openapi.json**
PostgeSQL будет доступен по адресу **127.0.0.1:5432**
```

Другие команды управления:
```bash
bash backend_init.sh down # Убить контейнеры
bash backend_init.sh up [api | db | redis] # Поднять определенный сервис
bash backend_init.sh down [api | db | redis] # Убить определенный сервис
```
